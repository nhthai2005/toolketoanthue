Word Debt Filter

Filter debt rows in Word files

Upload a .docx or .docm file. The page will remove rows where the Debt Amount column is 0 or empty, then recalculate the total row.

Key benefit
Simple flow

Open a document, run the filter, and save the cleaned result with a calmer, more guided experience.

  • Only Word files in `.docx` and `.docm` format are supported.
  • In Chrome or Edge, “Open from folder” lets the result be saved back to the same folder.
